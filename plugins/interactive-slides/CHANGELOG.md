# Changelog

All notable changes to Interactive Slides are documented in this file.

## 0.6.0

- Added proposal-first intake, scope estimation, revision and explicit approval gates.
- Added slide-by-slide production proposal and feedback templates.
- Added an approval validator that blocks production while decisions remain unresolved.

## 0.5.0

- Moved demo and experience mode selection into authoring intake.
- Replaced presentation utility labels with accessible SVG icon controls.
- Added commercial presentation visual-quality and anti-slop guidance.

## 0.4.0

- Added timeline, diagram, code walkthrough and before/after scene recipes.
- Added the nine-slide HTML starter, scene lifecycle controls and project validators.
