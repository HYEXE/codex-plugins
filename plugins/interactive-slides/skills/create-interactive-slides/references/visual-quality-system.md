# 상용 발표 수준의 시각 품질 체계

상용 프레젠테이션 제품은 복제할 template이 아니라 완성도 기준으로 사용한다. 재사용 가능한 원칙을 도출한 뒤 사용자의 콘텐츠와 brand에 맞는 독창적인 art direction을 만든다.

## Layout 전에 정할 art direction

Slide 제작 전에 각 항목을 한 문장으로 정의한다.

- editorial premise: deck이 전달해야 할 인상
- typography: display face, reading face와 numeral treatment
- palette: background, foreground, accent와 semantic color
- image treatment: crop, mask, grading, caption과 credit style
- geometry: grid, margin, corner language, line weight와 icon style
- motion language: 하나의 transition family와 하나의 emphasis pattern

제공된 brand system을 우선한다. 없다면 editorial report, cinematic keynote, restrained corporate, data publication 또는 workshop canvas처럼 하나의 일관된 방향을 선택한다. Slide마다 서로 다른 방향을 섞지 않는다.

## Slide-family 체계

하나의 범용 card layout을 반복하지 말고 소수의 master family를 만든다.

- cover와 section divider
- statement 또는 quote
- 출처가 있는 evidence
- image-led narrative
- comparison 또는 decision
- process, timeline 또는 diagram
- interactive scene
- closing takeaway

Family 전체에서 token은 일관되게 유지하되 composition, scale과 whitespace를 달리해 rhythm을 만든다. 중요한 slide는 thumbnail로 보아도 다른 silhouette을 가져야 한다.

## AI 상투 표현 방지 규칙

콘텐츠가 명시적으로 요구하지 않는 한 다음과 같은 기본 생성 흔적을 피한다.

- 대부분 slide에 반복되는 3~4개의 rounded card grid
- 이야기 목적이 없는 gradient, glow, blob 또는 glass panel
- 과도한 pill, badge와 작은 uppercase label
- 모든 요소에 같은 visual weight 부여
- emoji나 무관한 illustration style과 섞인 generic stock icon
- 문구를 다듬지 않아 어색하게 줄바꿈된 heading
- 만들어낸 metric, 장식용 chart 또는 가짜 product UI
- 모든 object에 반복되는 같은 reveal animation
- speaking cue가 아니라 문서처럼 동작하는 body text
- presentation chrome에 있어야 할 control을 slide 안에 배치

모든 장식 요소는 hierarchy, grouping, direction, evidence 또는 brand recognition을 지원해야 한다. 그렇지 않으면 제거한다.

## 전문적인 composition 규칙

- 의도적인 grid와 optical alignment를 사용하고 projector용 safe area를 일관되게 유지한다.
- 각 slide에 하나의 dominant idea와 하나의 dominant visual anchor를 둔다.
- 문구를 실제 공간에 맞게 편집하고, 글자가 많다는 이유만으로 type을 줄이지 않는다.
- 색을 추가하기 전에 scale, weight, position과 whitespace로 contrast를 만든다.
- Chart label을 읽을 수 있게 유지하고 발표 claim에 필요한 data만 보여준다.
- 출처와 용도에 맞는 고해상도 image를 일관된 crop과 credit 방식으로 사용한다.
- stroke, optical size와 bounding box가 일관된 하나의 icon family를 사용한다.
- Interactive control은 slide message보다 시각적으로 후순위에 둔다.
- Panel control은 accessible name과 tooltip이 있는 icon button으로 렌더링한다.

## Benchmark 검사

상용 template 제작자의 관점에서 deck 전체를 검토한다.

1. Thumbnail 검사: body text를 읽지 않아도 hierarchy와 rhythm이 보인다.
2. 거리 검사: projector에서 title과 핵심 숫자를 읽을 수 있다.
3. 일관성 검사: typography, color, grid, image treatment와 iconography가 일관된다.
4. 다양성 검사: 이유 없이 인접 slide에서 같은 composition을 반복하지 않는다.
5. 근거 검사: claim, simulation과 source를 시각적으로 구분할 수 있다.
6. Interaction 검사: control의 affordance가 분명하고 slide content처럼 보이지 않는다.
7. 마감 검사: orphan word, 우연한 wrapping, overflow, placeholder 문구와 출처 없는 asset이 없다.

간결한 문구, 읽을 수 있는 typography, 의미 있는 visual, 일관된 background와 contrast 기준은 [Microsoft PowerPoint의 효과적인 프레젠테이션 지침](https://support.microsoft.com/en-us/powerpoint/tips-for-creating-and-delivering-an-effective-presentation)을 참고한다.

응집력 있는 scheme, 전문적인 layout 대안과 긴 list의 시각화 기준은 [PowerPoint Designer](https://support.microsoft.com/en-US/PowerPoint/create-professional-slide-layouts-with-designer)를 참고한다.

재사용 가능한 brand color, font, text style, chart와 shape 체계는 [Pitch slide style](https://help.pitch.com/en/articles/4059534-create-your-own-slide-style)을 참고한다.
