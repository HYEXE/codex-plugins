# 근거 출처 레지스트리

- 스냅샷: 2026-08-06
- 등록 출처: 43개

이 레지스트리는 각 가이드가 참조하는 공개 자료의 역할과 안정성을 기록한다. 링크된 자료의 저작권과 상표는 각 권리자에게 있으며, 이 프로젝트는 원문 전체를 재배포하지 않는다.

## 근거 우선순위

1. 규범 표준과 공식 구현 지원 자료
2. 공공 서비스의 검증된 디자인·콘텐츠·접근성 지침
3. 공개 제품 디자인 시스템의 비교 가능한 패턴과 운영 경험
4. UX 연구·사용성·성능·윤리 분야의 전문 자료

서로 충돌할 때는 적용 법역·플랫폼·사용자 맥락을 확인하고, 접근성 표준과 사용자 안전 요구를 우선한다. 제품 디자인 시스템의 패턴은 보편 표준이 아니라 비교·구현 참고 자료로 취급한다.

## 활용 규칙

- 표준 문서는 요구사항을 판단하는 기준으로 사용하되, 실제 준수 여부는 구현과 테스트로 확인한다.
- 구현 가이드는 일반적 기법을 제공하지만 특정 프레임워크·브라우저·보조기술 버전의 현재 동작을 보장하지 않는다.
- 제품 디자인 시스템의 패턴은 해당 생태계의 선택이며 다른 제품에 그대로 복제하지 않는다.
- 연구·사용성 자료는 질문과 방법 선택을 돕지만 표본·도메인·시점의 한계를 기록한다.
- 시간 민감 자료는 적용 시점의 공식 문서에서 변경 여부를 확인한다.
